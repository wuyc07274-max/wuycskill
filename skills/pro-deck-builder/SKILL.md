# Presentation Designer — Pro Deck Builder

Create polished HTML slide decks and PDF-ready documents for consulting deliverables.

## Design Language: VC-Backed SaaS
- Depth through layering — surfaces float above backgrounds
- Bold typography, minimal decoration
- Restrained color — one accent at 10%
- Generous whitespace

## Color System
**Dark Mode** (default): bg #0A0A0C, text #FFFFFF
**Light Mode** (reports): bg #FFFFFF, text #111111

**Palettes**: Electric Blue, Neon Lime, Hot Coral, Indigo, Teal Trust, Amber Signal, Rose, Emerald, Cyan Edge, Violet, Slate, Gold Standard.

## Typography
Priority: Inter → DM Sans → Avenir Next → Poppins → Calibri
Data: JetBrains Mono → Fira Code → SF Mono

## Layout Grid (10" × 5.625")
Margins: 0.5", Content: 9" × ~4.5"

## Key Rules
- 85/10/5 color rule: 85% neutral, 10% accent, 5% semantic
- Scale font to character count for KPIs
- Left-align body, center only titles/KPIs
- Max 2 font families + 1 mono
- Chart numbers: OOXML conditional format with raw values
