# Xiaohongshu Cover Generator

Generate Xiaohongshu (小红书) style cover images based on user topics.

## Usage
1. User provides a topic or theme
2. Generate an HTML page with Xiaohongshu-style cover design
3. Capture as image and save to project directory

## Features
- Xiaohongshu-style aesthetics and layout
- Topic-based text overlay
- Styled typography matching XHS platform
- Output as image file for social media posting
