# 数学预习文档与组卷工具

为人教版高中数学提供两大功能：(1) 生成预习文档（学生版+教师版），含配图知识点梳理和习题；(2) 跨章节搜题组卷，按需求制作试卷或课后作业。

## 工作流概述
用户触发后选择模式：制作预习文档或制作试卷/作业。

### 模式一：预习文档生成
1. 选择教材（必修第一册/第二册/选必第一二三册）
2. 选择章节
3. 搜索知识点和习题
4. 确定配图需求
5. 生成 Word 文档（学生版+教师版）

### 模式二：试卷/作业生成
1. 需求确认（文档类型、考查范围、题型题量、难度）
2. 题目搜索与筛选
3. 整理与组卷
4. 生成文档（学生版+教师版）

## 格式规范
- 正文字体：宋体/黑体
- 学生版：不含答案
- 教师版：含答案与解析
