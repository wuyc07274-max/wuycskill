# 小红书笔记分析器 (XiaoHongShu Note Analyzer)

对小红书笔记进行全方位分析，提供优化建议，提升内容质量和曝光率。

## 分析维度
1. 内容质量 — 原创性、信息密度、逻辑结构
2. 关键词优化 — 搜索友好度、标签合理性
3. 标题吸引力 — 点击率、情绪共鸣、信息量
4. 敏感内容风险 — 违规词、广告嫌疑、平台规则
5. 商业化程度 — 种草 vs 硬广、转化潜力
6. 互动潜力 — 点赞、收藏、评论预期

## 适用场景
- 发布前审核
- 内容优化建议
- 提升笔记曝光率
- 小红书内容策略分析
